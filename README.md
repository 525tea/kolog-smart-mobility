# KOLOG
### 소량 화물을 공동화물로 구성하고, 철도 잔여용량과 연결하는 AI 기반 철도 물류 예약 서비스

> 화주가 화물 정보를 등록하면 서비스가 운송 조건을 분석하고 공동화물 후보 및 철도 운송안을 제안합니다. 철도 화차·열차의 잔여용량을 소량 화주와 연결해 운송 효율과 접근성을 높이는 것을 목표로 합니다.

철도 물류의 남는 공간을 새로운 기회로 연결하는 KOLOG 팀입니다.

## 1. 문제 정의

철도 화물 운송은 대량 계약 화주 중심으로 운영되어 왔습니다. 그러나 특송 및 내수 화물 증가로 소량·단발성 화물 수요가 늘면서, 소규모 화주가 철도 운송을 이용하기는 여전히 어렵습니다.

<img width="1764" height="1146" alt="image" src="https://github.com/user-attachments/assets/5d6f2729-9f79-4e92-b7f3-5235238bc2c9" />

### 철도 운영자의 문제

- 출발 전까지 판매되지 않은 화물 용량은 소멸하는 자원입니다.
- 대형 계약 화주 중심 구조로 신규 소량 화주를 확보하기 어렵습니다.
- 잔여용량과 소량 화주를 실시간으로 연결할 통합 거래·예약 플랫폼이 부족합니다.

### 소량 화주와 중소 판매자의 문제

- 소량 물량만으로는 철도 운송의 경제성을 확보하기 어렵습니다.
- 공동운송으로 비용을 분담할 수 있는 서비스가 부족합니다.
- 집하, 철도 운송, 라스트마일을 개별적으로 구성해야 합니다.
- 정기계약 없이 단발성 철도 용량을 확보하기 어렵습니다.

## 2. 서비스 개요

KOLOG는 소량 화주가 등록한 화물을 분석하여 운송 가능 조건을 판단하고, 조건이 유사한 다른 화물과 공동화물을 구성할 수 있도록 지원합니다.

이후 노선·일정·잔여용량 정보를 바탕으로 철도 운송안을 제안하고, 예약부터 운영자 승인 및 운송 상태 확인까지 하나의 흐름으로 제공합니다.

```text
화물 등록
  → 화물 정보 분석 및 검증
  → 출발/도착 권역의 철도 화물역 매칭
  → 공동화물 후보 및 철도 잔여용량 조회
  → 운송안 비교·선택
  → 예약 및 운영자 승인
  → 운송 상태·위치 확인
```

## 4. 핵심 기능

### 1. 화물 등록 및 운송 조건 입력

- 개별운송 / 공동화물 선택
- 출발지, 도착지, 희망 운송일, 화물가액 입력
- 일반화물 / 냉동·신선 화물 / 위험물 구분
- 자연어 입력 또는 항목별 입력 방식 제공
- PDF, 이미지, 엑셀, 텍스트 파일 첨부
- 분석된 화물 정보의 수동 보정
- 위험물 MSDS 업로드 및 보관
- MSDS가 확인되지 않은 위험물의 공동운송 참여 제한

### 2. 철도역·운송수단 매칭

- 지역별 철도 화물역 매핑
- 상세 지역명을 우선 반영한 역 추천
- 철도 지원 권역 외 지역 판정
- 권역 외 화물에 대한 도로 직배송 대안 제시
- 철도·도로 운송안 비교
- 예상 도로 운임, 화물 할증, 콜드체인 전력비 반영

### 3. 공동화물 및 예약

- 노선·날짜별 철도 잔여용량 조회
- 공동화물 후보 목록 및 상세 정보 제공
- 공동화물 참여 신청
- 적재량과 모집률 계산
- 조건에 맞는 화차 선택 지원
- 예약·결제 예상 금액 계산
- 적재보험 선택 및 플랫폼 수수료 반영
- 운영자 승인 기반의 예약 처리
- 모집중 / 승인대기 / 운송확정 / 운송중 상태 관리

### 4. 거래소·운송 현황

- 가격순, 용량순, 시간순 정렬
- 운행 예정 잔여용량 및 진행 중 운송 표시
- 알림 조회 및 읽음 처리
- 마이페이지에서 화물·예약·결제 내역 확인
- 데모 계정용 시연 데이터 제공
- 실시간 운송 위치 지도 및 단계별 타임라인 표시

## 5. AI 기능

KOLOG의 AI 기능은 화물 등록 편의성과 공동운송 후보 탐색을 지원합니다. 다만 위험물 운송 가능 여부와 운임 적용은 AI 응답만으로 확정하지 않으며, 규칙 엔진이 최종 검증합니다.

| 구분 | 기능 | 적용 상태 |
| --- | --- | --- |
| 1. 자연어 화물 분석 | 사용자가 작성한 자연어에서 품목, 수량, 중량, 출발·도착지, 희망 일정 등 구조화 가능한 정보를 추출 | 규칙 기반 대체 엔진 운영 / Gemini 연동 확장 예정 |
| 2. 첨부 문서 정보 추출 | PDF·이미지·엑셀·텍스트 등 첨부 자료에서 화물 관련 정보를 읽어 등록 항목 보조 | 입력·첨부 흐름 구현 / Google Document AI 연동 확장 예정 |
| 3. 화물 분류 및 운송 조건 판단 | 일반·신선·냉동·위험물 등 화물 특성과 필요한 운송 조건을 분류 | 규칙 기반 엔진으로 처리 |
| 4. 공동화물·운송안 추천 | 노선, 날짜, 적재 조건, 잔여용량을 바탕으로 공동화물 후보와 운송안을 제안 | 추천 로직 및 데이터 기반으로 고도화 중 |

### 안전 검증 원칙

- AI 추출 결과는 사용자가 수정·보완할 수 있습니다.
- 위험물 여부, MSDS 제출 여부, 공동운송 가능 여부는 규칙 엔진이 최종 검증합니다.
- 운임은 화물 유형, 할증, 냉장·냉동 조건, 운송 구간 등 정책 규칙을 반영해 계산합니다.
- AI 모델의 결과는 운송 정책과 안전 규칙을 우회하지 않습니다.

## 7. 주요 사용자 플로우
<img width="798" height="443" alt="image" src="https://github.com/user-attachments/assets/0f6e0288-368e-47d2-8ae3-7a5e22169bee" />


### 공동화물 예약

1. 화주가 출발지, 도착지, 희망일, 화물 특성을 입력합니다.
2. 시스템이 입력 정보와 첨부 파일을 분석해 화물 정보를 정리합니다.
3. 사용자는 분석 결과를 확인하고 필요한 항목을 수정합니다.
4. 서비스가 철도 화물역, 운송 가능 여부, 공동화물 후보를 조회합니다.
5. 사용자는 철도·도로 운송안을 비교하고 원하는 공동화물에 참여 신청합니다.
6. 예상 운임, 수수료, 보험 옵션을 확인한 뒤 예약합니다.
7. 운영자 승인 후 운송 상태와 위치 정보를 확인합니다.

### 위험물 화물 등록

1. 사용자가 위험물 화물을 선택합니다.
2. MSDS 파일을 업로드합니다.
3. 규칙 엔진이 MSDS 제출 여부와 공동운송 참여 가능 조건을 검증합니다.
4. 조건을 충족하지 못한 경우 공동운송 참여가 제한됩니다.
5. 조건 충족 여부에 따라 가능한 운송안만 제시됩니다.

## 8. 사용 예시

### 예시 1. 지역 신선식품 공동운송

강원 지역의 소규모 생산자가 수도권으로 신선식품을 보내려 합니다. 단독 운송으로는 비용 부담이 크지만, 동일 노선·유사 일정의 다른 신선 화물과 공동화물을 구성하면 철도 잔여용량을 활용한 운송안을 검토할 수 있습니다.

### 예시 2. 팝업스토어 긴급 재고 이동

중소 온라인 판매자가 행사장에 보낼 재고를 단발성으로 운송해야 합니다. 화물 등록 후 희망 도착 시간과 운송 조건에 맞는 철도 운송안 및 도로 운송안을 비교하여 선택할 수 있습니다.
