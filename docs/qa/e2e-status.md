# E2E 검증 현황

## 현재 미해결

- **PDF·이미지 OCR**: Google Document AI Form Parser 프로젝트/프로세서/서비스 계정이 아직 없어 배포 E2E를 실행할 수 없다.
- **XLS/XLSX 추출**: Apache POI 기반 구현 및 단위 테스트는 완료됐으며 Google 설정 없이 검증 가능하다.
- OCR 설정 전 배포에서는 `DOCUMENT_AI_ENABLED=false`를 유지한다. 파일 업로드 UI는 설정 부재를 명확한 오류로 안내해야 한다.

## 배포 후 필수 E2E 순서

1. 데모 원클릭 로그인 → 홈의 진행 중 운송·잔여용량 확인
2. 잔여용량 조회 → 날짜/노선 전환, 뒤로가기 확인
3. 거래소 → 가격순/용량순/시간순에서 순위와 강조값 변경 확인
4. 공동화물 상세 → 3개 참여사, 620kg, 5.5 CBM 확인
5. 일반화물 등록 → AI 분석 → 추천 → 가상 결제 → 예약 현황
6. 냉동화물 등록 → 온도/전력비/할증 확인
7. 위험물 1급 차단, 2~9급 MSDS·20% 할증 확인
8. 알림과 마이페이지의 예약·화물·결제 내역 확인
9. 운영자 로그인 → 적재 최적화 → 승인/반려 확인
10. 다른 화주 토큰으로 화물·예약 접근 시 403 확인
