# 공공데이터 참고자료

data.go.kr에서 다운로드한 한국철도공사(코레일) 실제 공개 데이터. API 키가 필요 없는 파일데이터라 그대로 커밋해둔다.

- `한국철도공사_화물 열차 운행 정보 데이터_20210101.xlsx` — 2020년 노선별·품목별 화물 수송실적(톤수).
  경부선·남부화물기지선(컨테이너), 중앙선(시멘트) 등 실제 주력 노선/품목 비중을 확인할 수 있다.
  출처: https://www.data.go.kr/data/15110034/fileData.do
- `한국철도공사_철도물류정보 홈페이지 화물자료실 정보_20240801.csv` — 코레일 화물정보 홈페이지 자료실 게시글 목록
  (제목/등록일/첨부파일명). "철도화물운송약관", "철도화물 탄력할인율" 등 실제 운임·할인 규정 문서의
  존재와 제목은 확인되지만, 첨부파일 자체(HWP 등)는 이 CSV에 포함돼 있지 않다.
  출처: https://www.data.go.kr/data/15133758/fileData.do

## 이 시스템에 어떻게 반영했나 / 안 했나

- **반영**: 두 파일 모두 노선/품목 "실적 통계"이거나 "문서 목록"이라, 우리 시스템이 필요로 하는
  실시간 잔여용량·화차별 제원 같은 구조화 데이터가 아니다. 그래서 매칭/가격 로직에 직접 넣지는 않았다
  — 대신 "컨테이너 화물이 실제로도 큰 비중을 차지한다" 같은 사실 확인 용도로만 참고했다.
- **미반영(중요)**: 화차 종류별 최대 적재중량, 실시간 잔여용량, 정식 운임표 같은 실제 수치 데이터는
  이번에 찾은 공개 자료로는 구할 수 없었다. `backend/src/main/resources/db/migration`의 열차/화차
  시드 데이터와 `PricingPolicy`의 운임 상수는 여전히 데모 시나리오에 맞춰 만든 가상 값이다.
